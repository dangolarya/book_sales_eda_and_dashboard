# book_sales_eda_and_dashboard
Link for interactive dashboard: https://booksales-dashboard.streamlit.app/

Introduction:
The Book Sales EDA with Dashboard project focuses on analyzing book sales data to identify sales patterns, customer preferences, and business insights. The project involves data cleaning, exploratory data analysis (EDA), and interactive dashboard creation to visualize important trends such as bestselling books, top-performing genres, customer purchasing behavior, and sales performance over time. The dashboard helps transform raw sales data into meaningful insights that support better business decisions and improve understanding of market trends.

Objectives:
- To perform data cleaning and preprocessing on raw book sales data.
- To analyze sales trends, customer behavior, and genre popularity.
- To identify bestselling books and high-revenue categories.
- To create interactive visualizations for better data interpretation.

Key Features:
- Interactive dashboard built using Streamlit.
- Sales trend analysis by month and year.
- Genre-wise and category-wise sales visualization.
- Identification of bestselling books and top authors.
- Customer purchasing behavior analysis.
- Data filtering and dynamic visual exploration.
- KPI metrics such as total sales, total orders, and average sales.
- Correlation analysis and graphical insights.

Areas to Improve:
- Add predictive analysis for future book sales forecasting.
- Improve dashboard UI/UX with advanced styling and animations.

Conclusion:
The Book Sales EDA with Dashboard project successfully demonstrates the process of transforming raw sales data into meaningful business insights through data analysis and visualization techniques. The project provides a clear understanding of sales performance, customer preferences, and market trends using interactive dashboards and analytical methods.
